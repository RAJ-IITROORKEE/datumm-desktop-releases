# DATUMM Desktop releases

Public distribution repository for unsigned Windows x64 DATUMM installers and the optional bundled Revit bridge. Application source and user data are not published here.

The [1.0.0-rc.1 unsigned candidate](https://github.com/RAJ-IITROORKEE/datumm-desktop-releases/releases/tag/v1.0.0-rc.1) includes the combined desktop installer, optional Revit alpha.29 installation, checksums, payload manifests and verification results. Web users can download the separate Revit installer from the same release. No stable release is published yet; the stable update feed remains empty.

Download [DATUMM for Windows x64](https://github.com/RAJ-IITROORKEE/datumm-desktop-releases/releases/download/v1.0.0-rc.1/DATUMM-1.0.0-rc.1-unsigned-win-x64.exe). Its SHA-256 is `2f2e75f0aab65516e883de728f0c6d8195c19df133048ad5061c641148c0855e`. The candidate uses the separate DATUMM Local Test identity and profile. Production Clerk configuration, clean-PC installation/upgrade and live Revit acceptance remain open.

Close DATUMM and Revit before running an upgrade. Installed user profiles are retained; local test and stable desktop profiles are separate. An unsigned installer may show Windows publisher warnings.
